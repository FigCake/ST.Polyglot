# Polyglot

> An integrated language learning extension for SillyTavern that turns your chats into an active study environment.

---

### Features

- **Input Assistant** — Translate or grammar-check your input before sending (🌍 button)
- **Annotation** — Highlight vocabulary by CEFR level and grammar patterns on any AI message
- **Tap to Translate** — Double-click a sentence (mouse), or select text and tap **Translate sentence** (touch), for an inline translation with verb forms
- **Quick Lookup** — Select any word to get its dictionary form, POS, IPA, and meaning
- **Wordbook + SRS** — Save words and review them with SM-2 spaced repetition. One shared wordbook, viewable per chat or across all chats
- **Backup** — Save and restore everything (words, review progress, sets, settings) as one JSON file
- **Furigana (Japanese)** — Readings over kanji with message analysis (📖) and on word cards, flashcards and the PDF deck; click a reading to correct it
- **Storage** — Your words live in `polyglot-data.json` in your SillyTavern user files (not in settings), so they follow you to every device that opens the same SillyTavern
- **Study Modes** — Flashcards, quiz, cloze, reading exam, conjugation drill, match, speaking
- **PDF Export** — Print-ready A5 flashcard deck with conjugation tables at the end

---

### Setup

1. Enable the extension in SillyTavern's extensions menu
2. Open the Polyglot panel → Settings tab
3. Set your target language, CEFR level, and AI provider

Supports SillyTavern's default connection or external APIs — OpenAI, Claude, Gemini, DeepSeek, OpenRouter, and any OpenAI-compatible endpoint.

---

### Requirements

- SillyTavern
- AI provider with 8k+ context window recommended
- Chrome or Edge for pronunciation features (Web Speech API)
